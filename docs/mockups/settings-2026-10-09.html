Every /aux command, and where it goes

From the CurseForge page. Every chat command keeps working either way; this is only about which ones also get a switch in the menu.

In the menu on/off settings players change

/aux tooltip value, daily, merchant sell, merchant buy, disenchant value, disenchant distribution, money iconsTooltip lines
Seven switches. Built in build 2 as checkboxes; this turns them into switches.
/aux post bidPosting
Recommended, new. Off, per item or per stack, so three choices rather than a switch. It only shows a column, so it cannot cost anyone money.

Already in the menu

/aux scaleWindow, Scale
/aux opacityWindow, Background
/aux post durationPosting, Default duration
/aux undercut on|offPost tab (goblin switch)
Starts off every visit on purpose, so it stays on the Post tab where you use it.

Your call click Try it to see the row

/aux ignore owner
Shows the same price from different sellers as one row (on now) or one row per seller. Forever often hides seller names anyway ("4 sellers"), so turning it off changes little. I'd leave it out.
/aux action shortcuts
Alt-click buys gear at once and a stack in two clicks. You flagged it as risky. I'd leave it out.
/aux debug
Prints search timings in chat for bug reports. You said no to debug in the menu. Leave it out.

Stays in chat only not settings

/aux price <item>a lookup
/aux memory, /aux debug listdiagnostics
/aux clear item cache, /aux clear postdelete saved data
A button for these in the menu would be easy to hit by accident.

Why it was mostly tooltips

Of the commands on the CurseForge page, the true on/off settings are the seven tooltip lines plus ignore owner, action shortcuts and debug. Scale, background and duration were already in the menu. So the real choices are the three "Your call" rows and the bid prices.

My recommendation: switches for the tooltip lines, add bid prices under Posting, leave the three "Your call" commands as chat only.
