Second opinions from Gemini (the supporting model) on Claude Code's work (Tyler, 2026-10-26). The
rules are in `AGENTS.md`, "Roles".

One file per review: `<date>-<topic>.md`, Tyler's date. At the top: the date, the branch and the
commit reviewed. Then one numbered finding each: what, where (file and line), why it matters to a
player, and how sure (a fact from the code or the game, or a guess). Claude answers under each
finding: fixed (with the commit), not reproduced, or not worth its cost and why.
